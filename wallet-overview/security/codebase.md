# Codebase

Our codebase is fully open-source and publicly available on GitHub via the link provided below:&#x20;

{% embed url="https://github.com/cape4labs/sunflower_wallet_app" %}

The project is distributed under the [MIT License](https://dev.to/ahmmrizv9/mit-license-explained-a-deep-dive-into-open-source-permissiveness-and-fair-code-practices-3ni3?ysclid=mkfbnbchav738674386), which allows free use, modification, and further development of the code. This permissive licensing model encourages community contributions and also improves potential security, as the open nature of the code enables independent review and auditing.

All commits are published directly to GitHub, and the full development history of the project is available in the repository. This ensures transparency of the creation process and allows anyone to track changes and improvements over time.

All project data is obtained exclusively through the [Hiro API](https://github.com/cape4labs/sunflower_wallet_app) and the [CoinGecko API](https://www.coingecko.com/en/api), providing reliable and verifiable external data sources that are clearly integrated into the open-source codebase.
